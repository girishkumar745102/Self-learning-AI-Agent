#Self-Learning AI Agent

A Python-based AI agent project focused on building a long-term memory system using vector embeddings and ChromaDB.

#Current Features

- Stores user memories
- Converts text into embeddings using Sentence Transformers
- Saves embeddings in ChromaDB
- Retrieves relevant memories using similarity search
- Supports user-specific memories

#Technologies

- Python
- ChromaDB
- Sentence Transformers
- "all-MiniLM-L6-v2"

📁 Project Structure

Self-learning-agent/
├── memory.py

▶️ Run

Install dependencies:

pip install -r requirements.txt

Run the memory system:

python memory.py
